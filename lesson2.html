Lesson 2: Functions, Equations and Graphs

Understand functions, domain and range, equations, and graphical representations used in college-level mathematics.

1. What is a Function?

A function is a mathematical relationship in which every input is associated with exactly one output.

Example Consider the function:
f(x) = 2x + 3
If x = 4:
f(4) = 2(4) + 3 = 11

2. Domain and Range

The domain of a function is the set of possible input values.

The range is the set of possible output values produced by the function.

Example For:
f(x) = x²
If the domain is all real numbers, the range is:
f(x) ≥ 0

3. Linear Functions

A linear function generally has the form:

y = mx + c

Here, m represents the slope and c represents the y-intercept.

Example Consider:
y = 3x + 2
The slope is 3 and the y-intercept is 2.

4. Quadratic Functions

A quadratic function is generally written as:

f(x) = ax² + bx + c

Its graph is a parabola. Quadratic functions are widely used in physics, economics, engineering and other applied fields.

5. Equations

An equation states that two mathematical expressions are equal. Solving an equation means finding the value of the unknown variable that satisfies the equation.

Example Solve:
2x + 5 = 15
Subtract 5:
2x = 10
Divide by 2:
x = 5

6. Understanding Graphs

Graphs provide a visual representation of mathematical relationships. They allow us to identify trends, compare values and understand how one variable changes with respect to another.

Real-World Application Suppose a company's revenue depends on the number of products sold. A graph can help management understand how changes in sales affect revenue.

Quick Summary

Functions establish relationships between inputs and outputs. Domain and range describe the possible inputs and outputs. Linear and quadratic functions are important mathematical models, while equations help us determine unknown quantities. Graphs provide a visual way to analyze these relationships.
