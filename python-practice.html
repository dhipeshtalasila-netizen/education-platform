Question 05

Factorial

Write a program to calculate the factorial of a number.

Use a loop and multiply the values.
n = 5
factorial = 1

for i in range(1, n + 1):
    factorial *= i

print(factorial)
Question 06

Prime Number

Write a program to check whether a number is prime.

Check whether the number has divisors other than 1 and itself.
n = 17
is_prime = True

if n < 2:
    is_prime = False
else:
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            is_prime = False
            break

print(is_prime)
Question 07

Fibonacci Series

Generate the first 10 numbers of the Fibonacci series.

Start with 0 and 1, then add the previous two numbers.
a = 0
b = 1

for i in range(10):
    print(a)
    a, b = b, a + b
