Lesson 4: Integration and Applications

Learn the fundamental concepts of integration, basic integration rules and important applications of definite and indefinite integrals.

1. Introduction to Integration

Integration is an important concept in calculus. It can be understood as the reverse process of differentiation.

Integration is also used to calculate quantities such as area, displacement, accumulated change and total values.

Basic Idea If:
d/dx (x²) = 2x
then:
∫ 2x dx = x² + C
Here, C represents the constant of integration.

2. Indefinite Integral

An indefinite integral represents a family of functions whose derivative is the given function.

∫ f(x) dx = F(x) + C

The constant C is included because the derivative of any constant is zero.

3. Power Rule of Integration

For most powers of x, the power rule can be used to find the integral.

∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C

This rule applies when n ≠ -1.

Example Find:
∫ x² dx
Increase the power by 1:
x³
Divide by the new power:
∫ x² dx = x³/3 + C

4. Integration of a Constant

When integrating a constant, multiply the constant by x.

∫ a dx = ax + C
Example
∫ 5 dx = 5x + C

5. Definite Integral

A definite integral has upper and lower limits. Unlike an indefinite integral, its result is generally a numerical value.

∫ₐᵇ f(x) dx

The limits indicate the interval over which the function is integrated.

6. Area Under a Curve

One of the most important applications of definite integration is finding the area under a curve.

Example The area under a function f(x) between x = a and x = b can be represented as:
Area = ∫ₐᵇ f(x) dx

7. Integration and Motion

Integration can also be used in physics to determine displacement from velocity.

Example If velocity is:
v(t) = 2t
then displacement is obtained by integrating:
s(t) = ∫ 2t dt
Therefore:
s(t) = t² + C

8. Applications in Economics

Integration is also useful in economics and business mathematics.

It can be used to determine total cost, total revenue, accumulated production and other quantities when their rates of change are known.

Quick Summary

Integration is the reverse process of differentiation. It can be used to find antiderivatives, areas, displacement and accumulated quantities. Both indefinite and definite integrals are important concepts in college-level mathematics.
