About C++

C++ is a powerful general-purpose programming language developed by Bjarne Stroustrup. It extends the C programming language with object-oriented programming, generic programming and many other powerful features.


C++ is widely used for software development, game development, operating systems, embedded systems, high-performance applications, competitive programming, algorithms and data structures.
